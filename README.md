# 🎓 Student Management System

A desktop-based **Student Management System** developed using **Python**, **Tkinter**, and **MySQL**. This application helps manage student records efficiently through an easy-to-use graphical interface.

---

## 📌 Project Overview

The Student Management System is designed to simplify student record management. Users can securely log in, connect to a MySQL database, and perform operations such as adding, searching, updating, deleting, viewing, and exporting student records.

---

## 💡 Features

- 🔐 Secure Login System
- 🗄️ MySQL Database Integration
- ➕ Add Student
- 🔍 Search Student
- ✏️ Update Student
- ❌ Delete Student
- 📋 View All Students
- 📤 Export Data to CSV
- 🕒 Real-Time Date & Time Display
- 🎨 Modern GUI using Tkinter & ttk Themes

---

## 🛠️ Technologies Used

- Python 3

## 🚀 How to Run

1. Install Python 3.
2. Install the required libraries:

```bash
pip install pymysql pandas pillow ttkthemes
```

3. Make sure MySQL Server is running.
4. Run the login file:

```bash
python login.py
```

5. Login using:

```
Username: lavi
Password: lavi
```

6. Connect Database

```
Host Name: localhost
User Name: root
Password: lavi
```

7. Connect to your MySQL database and start managing student records.
